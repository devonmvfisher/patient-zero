GENERATOR (fixed now):
  page_instruction: random.Random(20261035) draws anchor rows from all agent rows. Page P = the anchor's page,
  t0 = the anchor's time. Each page is tried once (a later draw of a tried page is skipped).
  Writers = agents with a save on P in [t0, t0 + 72 h]. Each writer follows with probability 0.35 on its own
  coin: the first 8 bytes of sha256("20261035" + 0x1F + P + 0x1F + agent label), read as an integer and divided
  by 2^64, is below 0.35. No other agent, no order and no earlier use enters the coin.
  A follower's use row is its first save on P in the window (one row per follower). No cap. No planted contact.
  A page is kept when it has at least 5 followers (E6's floor: a seed plus at least 4 adopters).
  Stop at 40 pages (budget 20,000 draws). The kind has its own generator, so every E7 planting is unchanged
  (unit test).
